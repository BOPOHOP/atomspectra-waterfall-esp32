# AtomSpectra Waterfall — прошивка 1.2.28

Релиз (не пред-релиз). Главное — автоматическое считывание калибровки с прибора и зачистка известных
ошибок: в этой версии исправлено всё, что можно исправить без изменений в самом приборе.

## Новое

- **Калибровка с прибора — автоматически.** Если на плате калибровка не задана (все коэффициенты нули),
  при старте набора — вручную или автозапуском — плата сначала запрашивает калибровку у прибора и,
  если та считалась корректно (контрольная сумма сошлась), применяет её сама. Пустая калибровка
  прибора не применяется; кнопка «Считать» в этом случае сообщает, что калибровка платы не изменена.
- **Слепок настроек DSP прибора.** Страница «Сервис»: сохранить текущие настройки прибора на плату
  и скачать последний сохранённый слепок. Запись идёт через временный файл — неудачная запись не
  портит предыдущий слепок.
- **Экспорт n42 полной истории водопада** — отдаётся потоком с флеш-памяти, а не только последние
  строки из памяти (прежний режим — `?ring=1`).

## Исправлено

- Дамп калибровки, пришедший сразу после ответа `-ok`, терялся — калибровка не применялась.
- Разбор дампа калибровки устойчив к мусору перед дампом, нулевым байтам и дроблению на пакеты;
  серийник прибора берётся только из целого, проверенного дампа.
- Нулевая калибровка больше не считается «заданной» на страницах и в файлах экспорта.
- Оверлей сохранённого спектра в режиме CPS делится на своё время набора, а не на время живого.
- Экспорт n42 после неудачной очистки водопада больше не дублирует и не теряет строки.
- Номер сегмента водопада не откатывается после стирания настроек.
- Сегмент водопада, который сейчас скачивается, защищён от удаления.
- Бюджет ожидания доступа к флеш-памяти для веб-запросов увеличен — меньше ложных отказов при
  фоновой записи.
- Автосохранение не запускается во время обновления прошивки.
- Обновление с GitHub: докачка после обрыва Wi-Fi, повторы при сбое сети (но не при ошибке сервера),
  отдельное сообщение «установка старой версии запрещена».
- Кэш спектра для веб-страниц больше не теряет сигнал обновления на гонке.
- Демо-страницы приведены в соответствие с рабочими.

## Обновление

- По Wi-Fi: вкладка «Система» → «Обновление прошивки» → «Установить с GitHub», либо вручную
  `atomspectra_gw.bin` через тот же раздел.
- Через USB: `firmware.factory.bin` через `esptool write_flash 0x0`.

## Проверка целостности

Сверяйте `SHA256SUMS.txt` перед установкой.

## Проверено перед выпуском

- Стабильность: непрерывная работа на плате 65 мин — 0 перезагрузок, набор без разрывов, утечки памяти
  нет (свободная память +1,3 КБ/ч).
- Производительность: время ответа страниц и API на прогретой плате — в пределах ±20 % от прошлого
  замера или быстрее; под нагрузкой в 1–3 вкладки — без ошибок и быстрее прошлого замера.
- Функции проверены на живом приборе: автосчитывание калибровки (дважды), ручное считывание, экспорт
  n42 полной истории (501 строка), слепок настроек DSP, оверлей в режиме CPS, все страницы.
- Код: четыре независимых разбора изменений; нерешённых критичных и серьёзных находок — 0.
