# AtomSpectra Waterfall — прошивка 1.2.36

Релиз (не пред-релиз). Разгрузка веб-интерфейса платы: опросы страниц не идут в скрытой вкладке и разнесены по времени,
пул сокетов веб-сервера увеличен, страница не остаётся пустой при сбое загрузки общего скрипта.

## Новое

- **Разброс опросов страниц по времени (джиттер ±12 %).** Период каждого опроса умножается на `1 + u`, где `u` случайно
  в пределах от −0,12 до +0,12; первый вызов делается через случайное время от 0 до 0,3 периода. Несколько открытых
  вкладок и страниц перестают бить в плату одновременно. Цепочка `setTimeout` вместо `setInterval`.
- **Пул сокетов веб-сервера 11 → 19.** `config.max_open_sockets` с 11 до 19; сокеты lwIP (`CONFIG_LWIP_MAX_SOCKETS`) с 16 до 24,
  `CONFIG_LWIP_MAX_ACTIVE_TCP` с 16 до 24 (предел растёт вместе с числом сокетов).
- **Повтор загрузки `common-time.js` и сообщение вместо пустой страницы.** Если общий скрипт не загрузился (сброс соединения,
  503, таймаут), страница один раз перезагружается сама; при повторном сбое в пределах 30 с вверху страницы показывается
  сообщение на русском и английском с просьбой нажать F5. Цикла перезагрузок нет; при заблокированном
  `sessionStorage` автоперезагрузки нет, сообщение показывается сразу.
- **Защита сборки от устаревшего `sdkconfig`.** Файл `sdkconfig.defaults` применяется только при создании `sdkconfig`;
  старый `sdkconfig` молча оставлял 16 сокетов при 19 у веб-сервера. Новый `main/socket_budget.h` останавливает сборку
  (`#error`), если `CONFIG_LWIP_MAX_SOCKETS` или `CONFIG_LWIP_MAX_ACTIVE_TCP` меньше 24; в сообщении сказано, что удалить
  `sdkconfig` и `build/sdkconfig` и выполнить `idf.py reconfigure`.

## Также в выпуске (оптимизация нагрузки на плату и страницы)

- Опрос страниц не идёт в скрытой вкладке и возобновляется сразу при возврате (`pollWhileVisible`); не входит в функцию
  повторно, пока предыдущий запрос не завершён.
- Общий код страниц вынесен в `common-time.js`: обёртки CSRF, каркас i18n, время и длительности, полином энергетической
  калибровки. `/common-time.js` отдаётся с `ETag` и `Cache-Control: no-cache`, на совпавший `If-None-Match` — 304 без тела.
- Среднее CPS (SMA) главной считает плата по своему кольцу мониторинга: `GET /api/spectrum/meta.json?w=<сек>` добавляет
  поля `sma`, `sma_w`, `sma_n`; запрос без `w` отвечает по-прежнему. Окно среднего — «Интервал усреднения, с» вкладки
  «Мониторинг» (при отсутствии значения — 10 с; меняется сразу при вводе, не только при «Старт»). На главной после
  дроби выводится только число (`98 / 177.62 CPS`), без подписи «SMA <окно> с»; фактический охват окна — во всплывающей подсказке.
- Кэш `/api/spectrum*`: снимок без блокировки (seqlock), поля `meta` собираются один раз, полный JSON — по требованию.
- `/api/system`: обходы кучи и опрос стеков задач выполняются не чаще раза в 10 с и кэшируются. В `/api/system`
  добавлены счётчики `spectrum_build_us`, `spectrum_build_us_max`, `heap_walk_n`, `autosave_writes`.
- `/api/device` не выделяет буфер около 33 КБ. Одна формула живого времени вместо двух копий.
- Неизменный `current.bin` не переписывается одноразовым автосохранением.
- Вёрстка на 375 px: таблица «Сохранённые» на главной прокручивается внутри панели, шапка Мониторинг / Система / Сервис
  переносится.
