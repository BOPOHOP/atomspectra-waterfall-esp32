# AtomSpectra Waterfall — прошивка 1.2.31

Релиз (не пред-релиз). Изменение только в веб-интерфейсе страницы спектра.

## Изменено

- **Журнал обмена с прибором** вынесен в отдельную секцию под блоком «Калибровка энергии». По умолчанию она
  свёрнута (раскрывается по клику на заголовок, рядом — число строк). Раньше строки журнала выводились под
  кнопками управления и занимали место на странице.
- **Сохранение журнала в файл.** Кнопка «Сохранить в файл» скачивает журнал текстом
  (`atomspectra-exchange-ГГГГММДД-ЧЧММСС.txt`, первая строка — дата и время сохранения). Кнопка «Очистить» стирает журнал.
- Журнал хранит до 500 строк (было 50), ответы прибора показываются целиком, без обрезки до 120 символов;
  многострочные ответы склеиваются в одну строку через « ⏎ ».
- Время у строк — момент получения ответа прибором (как в 1.2.30).

## Тесты

Проверки и мутанты хост-тестов `wiring_check.sh` / `mutate_wiring_f01.sh` обновлены под новую секцию; мутанты
теперь применяются и к рабочей копии с окончаниями строк CRLF.
