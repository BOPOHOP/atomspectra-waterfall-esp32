# AtomSpectra Waterfall — прошивка 1.2.27

Релиз (не пред-релиз). Продолжает 1.2.26-rc2, добавляет только перекомпоновку вкладки «Система».

## Что изменилось

- Вкладка «Система» полностью переверстана по макету: пять компактных плиток-сводок сверху
  (Плата / Heap / Flash / WiFi / Прибор), подробности раскрываются по клику.
- Разделы «Сеть и время», «Измерения», «Обслуживание» сгруппированы в ряды из трёх карточек
  вместо разрозненного grid.
- «Точка доступа (AP)» — новая карточка, в неё перенесён переключатель ухода в AP при потере Wi-Fi.
- «Обновление прошивки» и «Опасные действия» — в один ряд; кнопки опасных действий выровнены
  по ширине.
- Высоты карточек внутри каждого ряда выровнены (разброс ≤15 px), убраны пустые места снизу
  у коротких карточек — в том числе устранена зависимость высоты карточки «Мощность дозы» от
  языка интерфейса (перенос текста подсказки на 1 или 2 строки).
- Все идентификаторы элементов, обработчики и обращения к `/api/*` не менялись — только
  разметка и раскладка.
- То же самое приведено в соответствие в демо-странице `demo/system.html`.

## Обновление

- По Wi-Fi: вкладка «Система» → «Обновление прошивки» → «Установить с GitHub» (если включён
  канал предрелизов — предложит эту версию как обычный релиз; без канала предрелизов эта версия
  видна как последняя стабильная).
- Вручную: `atomspectra_gw.bin` через тот же раздел, либо `firmware.factory.bin` через
  `esptool write_flash 0x0`.

## Проверка целостности

Сверяйте `SHA256SUMS.txt` перед установкой.
