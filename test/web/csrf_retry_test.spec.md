Write a Node.js ES module test script (file `test/web/csrf_retry_test.mjs`). Output ONLY the JavaScript code, no markdown fences, no explanations.

Purpose: the shared web helpers in `web/common-time.js` are plain global functions `async function loadCsrf()`, `async function post(url,opts)` and `async function gget(url,opts)` that use a global variable `csrfToken`. `post` and `gget` must, when the server answers HTTP 403 (stale CSRF token), call `loadCsrf()` once to refresh `csrfToken` and repeat the request exactly once. Additionally `web/waterfall.html` has a thin wrapper `function postJson(url,obj)` that calls the global `post`.

Requirements:
1. Imports: `readFileSync` from "node:fs". Usage line in the first comment: `node test/web/csrf_retry_test.mjs [common-time.js [waterfall.html]]`. `process.argv[2]` = path of the JS file (default `web/common-time.js`), `process.argv[3]` = path of the waterfall page (default `web/waterfall.html`). Run from repo root.

Sandbox builder: given the source strings, create `ctx = { csrfToken: "STALE" }` and variables `board = "NEW"` (the token the board currently accepts), `calls = 0`, `tokenFetches = 0`, `last = null`. Async `fetch(url, o)`: `calls++`; if `url === "/api/csrf-token"` then `tokenFetches++` and return `{ json: async () => ({ token: board }) }`; otherwise `last = { url, o }` and return `{ status: o.headers["X-CSRF-Token"] === board ? 200 : 403 }`. Instantiate with `new Function("fetch", "ctx", "with(ctx){ " + sources.join(";\n") + "; return { post: typeof post === 'function' ? post : null, gget: typeof gget === 'function' ? gget : null, postJson: typeof postJson === 'function' ? postJson : null }; }")(fetch, ctx)`.
